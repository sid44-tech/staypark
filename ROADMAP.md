# StayPark Roadmap

## Admin Portal

Build an admin portal where admins can manage hotel and airport information and manage users.

## Modernize the UI to React.js

Rebuild the application UI in React.js, replacing the current Thymeleaf pages.

## Containerize the App

Package the application in containers so it is easier to run locally and deploy.

## Feature Enhancements

Add new features and improve existing ones based on user and hotel feedback.

## Bug Fixes

Fix known bugs and keep dependencies up to date.
